نسخة جديدة كاملة. الموقع (عربي/إنجليزي) + الحجز بقاعدة بيانات + لوحة تحكم الدكتور.

> ✅ هذه النسخة **تم بناؤها والتأكد من نجاحها** قبل التسليم (`next build` + فحص الأنواع).

---

## ⚠️ اقرأ هذا أولاً — حتى ما تضيع شغلك مرة ثانية

بعد **كل** تعديل تعمله وينجح، ارفعه فوراً:

```
npm run build      ← تأكد إنه ما في أخطاء
git add .
git commit -m "وصف التعديل"
git push
```

التعديلات اللي ما تنرفع على GitHub بتضيع لو انحذف المجلد. هذا اللي صار سابقاً.

# التنصيب من الصفر

## ١. ثبّت المكتبات

افتح Terminal جوا المجلد (كليك يمين داخل المجلد → Open in Terminal):

```
npm install
```

## ٢. أنشئ قاعدة بيانات على Neon

1. افتح [console.neon.tech](https://console.neon.tech) → **New Project**
2. سمّيه `dental-clinic` واختر منطقة **Europe (Frankfurt)** — الأقرب للأردن
3. انسخ **Connection string**

## ٣. أنشئ ملف `.env`

```
copy .env.example .env
notepad .env
```

عبّي ثلاث قيم:

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | رابط Neon **مع** `-pooler` |
| `DIRECT_URL` | نفس الرابط **بدون** `-pooler` |
| `SESSION_SECRET` | نص عشوائي طويل (الأمر تحت) |

لتوليد `SESSION_SECRET`:
```
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

## ٤. جهّز الجداول

```
npx prisma generate
npx prisma db push
```

> استخدم `db push` مش `migrate dev` — لأنه Neon المجاني ما بيدعم قاعدة الظل (shadow database).

## ٥. أنشئ حساب الدخول

```
npm run seed
```
بينشئ: `dr.ahmad` / `changeme123`

## ٦. غيّر كلمة المرور فوراً ⚠️

```
npm run set-login
```

اختر كلمة قوية (12 خانة فأكثر، مش فيها اسم الدكتور). كلمة `changeme123` مكتوبة بملف الـseed على GitHub — أي حد يقدر يشوفها.

## ٧. شغّل

```
npm run dev
```

- الموقع: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin/login`

# النشر على Vercel

1. ارفع المشروع على GitHub (مستودع **خاص**)
2. [vercel.com](https://vercel.com) → **Add New → Project** → اختر المستودع
3. **قبل ما تضغط Deploy**، افتح **Environment Variables** وضيف نفس القيم الثلاث من ملف `.env`
4. **Deploy**

بعدها أي `git push` بينشر تلقائياً.

# شو فيه بالموقع

### الصفحة العامة
- فيديو العيادة بالأعلى مع زر كتم/تشغيل الصوت (يبدأ مكتوم)
- زر تبديل اللغة (EN / ع) — بيقلب النصوص والاتجاه
- **الشهادات والدورات** بقسم "عن الطبيب" (بدون عدد ساعات التدريب)
- **قبل وبعد**: ثلاث حالات، اسحب الخط لتشوف الفرق
- **الحجز**: المريض يختار تاريخ → يشوف الأوقات الفاضية **فعلياً** → يحجز

### لوحة التحكم `/admin/login`

**تبويب المواعيد:**
- كل الحجوزات مع حالتها (بانتظار / مؤكد / ملغي)
- زر "تأكيد وإرسال واتساب" — بيفتح واتساب المريض برسالة جاهزة، والحالة بتصير "مؤكد"
- زر إلغاء

**تبويب إدارة الأوقات — الجديد:**

تقدر تقفل:
- **ساعة محددة** — مثلاً 3:00 م بس
- **فترة كاملة** — صباحاً (9–12) / ظهراً (1–5) / مساءً (6–9)
- **اليوم كامل**

الأوقات المقفلة ما بتظهر للمرضى. وإذا حاولت تقفل وقت فيه حجز، بيرفض وبيقولك اسم المريض — لازم تلغي الحجز وتبلغ المريض أولاً.

# ⚠️ أمور مهمة قبل التسليم للدكتور

1. **غيّر كلمة مرور الدكتور** — لا تتركها `changeme123`
2. **موافقة المرضى**: صور "قبل وبعد" لمرضى حقيقيين — تأكد إنه في موافقة على نشرها
3. **لا ترفع ملف `.env` على GitHub** — هو مستثنى بـ`.gitignore`، خليه هيك
4. **راجع نصوص الشهادات** مع الدكتور قبل النشر — هي مؤهلات طبية ولازم تكون دقيقة
5. راقب استهلاك Neon المجاني لو زاد عدد الحجوزات
